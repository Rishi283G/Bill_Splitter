# 💸 Bill Splitter Web App

A simple and modern web app to calculate and split bills with a tip. Built using **HTML**, **CSS**, and **JavaScript**.


## ✨ Features

- Input total bill amount (₹)
- Choose tip percentage (preset or custom)
- Enter number of people
- See calculated:
  - Tip amount
  - Total bill
  - Each person's share
- Reset button to clear all fields
- Fully responsive layout
